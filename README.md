# AI 工作台

面向 macOS 的本地桌面应用，用项目组织仓库、文档、附件和脚本，也可以在独立临时目录中打开终端和原生 Agent。

## 启动

需要 Node.js、Rust、macOS 开发工具，以及创建仓库所需的 Git。使用项目中的依赖构建：

```sh
npm install
npm run tauri -- dev
```

打包桌面应用：

```sh
APPLE_SIGNING_IDENTITY='-' npm run tauri -- build --bundles app
```

应用位于 `src-tauri/target/release/bundle/macos/AI 工作台.app`。上面的命令使用本地临时签名，未使用 Apple 开发者证书，也未进行公证；适合本机使用。首次启动时选择一个空目录作为工作台；已初始化的工作台目录可再次选择。

## 使用

- 在侧栏创建项目，并分别管理 Git 仓库、文档和附件。脚本资源与自定义快捷按钮位于“快捷按钮”页面。
- 无需创建项目，可在侧栏新建临时目录，浏览和编辑其中的文件，打开终端或启动原生 Agent，并查看和恢复该目录的历史会话。临时目录会保留到手动删除。
- 在项目文件中直接新建文件和文件夹；在项目概览中创建文档、脚本、克隆仓库或选择附件时，资源保存到工作台并自动关联当前项目。选择的附件会复制，原文件保留。
- 在项目概览中关联资源；同一资源可以关联到多个项目。项目配置存于项目目录的 `.personal-workbench.json`，关联入口为指向工作台资源的软链接。外部修改配置后，可在应用中刷新。
- Markdown 文档使用分栏编辑器与实时预览，支持常见 GFM 语法；普通文本仍可直接编辑，仓库支持代码浏览和轻量编辑。保存时若文件已被外部修改，可以保留草稿、载入外部版本，或明确选择用草稿覆盖。项目文件可以整理为独立文档、附件或脚本。
- 项目、资源和临时目录删除时移入 macOS 废纸篓；删除仍被项目关联的资源前，先解除各项目的关联。删除临时目录不会删除原生 Agent 自身的历史会话记录。
- 在设置中选择终端、Git 软件和编辑器；Codex、Claude Code、Pi 需要分别安装。历史会话读取还需要本机 Node.js；检测不到程序时可在设置中填写其可执行文件路径。
- Codex 会话列表读取其本机索引；尚未进入索引的历史会话可能不会显示。

工作台不会自动导入或迁移现有资料。项目概览可扫描项目目录、已关联仓库以及工作台文档库中尚未关联到当前项目的 Markdown 文件。用户关联项目或仓库中的文件时，文件会移入工作台文档目录并在原位置保留软链接；关联文档库中已有的文件时，只建立项目关联，不移动文件。附件仅在用户主动选择时添加，仓库由用户指定地址克隆。项目页面的“刷新工作台”会重新读取配置并扫描 Markdown。工作台助手和 AgentBridge 接入不在第一版范围内。产品目标与验收范围见 [项目规划](ai-workbench-plan.md)。

## 验证

使用 `npm test` 运行会话读取器回归测试，使用 `cargo test --offline --manifest-path src-tauri/Cargo.toml` 运行本地工作台与 Agent 接入测试。
